2. Entrar na pasta do projeto
3. Npm install para instalar as libs
4. Pra rodar o bot, "node chatbot.js"
5. Ler o QR Code para conectar-se ao seu Whatsapp
6. Para configurar o alerta de SMS, pelo WhatsApp Web coloque console.log(client.info);
7. Copie o ID e altere no topo do código
